# Deploy multilingual phase 1

1. Download and extract this ZIP.
2. Upload/commit the package contents to the root of the existing `main` branch, preserving the root English files.
3. Ensure GitHub Pages serves directories as `/id/`, `/pt-br/`, `/es/`, `/ar/`, `/fr/`, `/hi/`, `/bn/`, and `/tr/`.
4. Check representative URLs in each language, especially the download form, language menu, and Arabic right-to-left layout.
5. Submit `https://tiktokdownloader.online/sitemap.xml` in the matching non-www Search Console property.
6. Inspect the pages and sitemap before requesting indexing.

The root English pages have been updated with reciprocal `hreflang` links and a language selector. Locale pages use self-canonicals. The sitemap contains 54 URLs and includes alternate-language declarations.
